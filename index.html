Why it feels light

Motion with a frame budget.

Every pattern is drawn on one 2D canvas, scaled for the screen's pixel ratio, and paused when the tab is hidden.

≤ 2 ms / frame

Fits the frame

Patterns stay well under the 16.7 ms a 60 Hz display allows, so scrolling and typing stay smooth.

4.8 kB gzipped

One small script

No WebGL, no dependencies. Drop it before your closing body tag and it finds its own canvas.

prefers-reduced-motion

Calm by request

Visitors who ask for less motion get a still frame of the same pattern, never a blank page.

pointer + touch

Reacts to people

Nodes lean toward the cursor, ripples spread from taps, and everything settles when the hand leaves.

light · dark

Follows the theme

Colors come from your CSS custom properties, so a theme switch repaints the field instantly.

seeded

Repeatable

Pass a seed and every visitor sees the same layout. Leave it out for a fresh arrangement per visit.

Install

Three lines to a living page.

<!-- before </body> -->
<script src="https://cdn.example.com/kinetica@2.1/kinetica.min.js"></script>
<script>
  Kinetica.mount({ pattern: "constellation", speed: 1, density: 1, palette: "ember" });
</script>
